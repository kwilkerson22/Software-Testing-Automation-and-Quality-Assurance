# Software-Testing-Automation-and-Quality-Assurance

**How can I ensure that my code, program, or software is functional and secure?**

I ensure that my software is functional and secure by doing regular code reviews to look for syntax or logic errors. I also use a combination of static and dynamic testing to discover any bugs that exist. I also conduct unit, integration, system and acceptance testing to make sure that all requirements have been met before deployment. 

**How do I interpret user needs and incorporate them into a program?**

I clarify my requirements by conducting interviews and creating user personas that establish different use cases. I also make sure that I have detailed documentation so that I can keep track of how requirements change over time.

**How do I approach designing software?**

I have become a supporter of Test Driven Development (TDD). First, I write the test cases which helps me understand the requirements and visualize what the program is supposed to do. From there, I develop the code as efficiently as I can while also passing the various test cases. After that, I refactor the code if I notice any improvements can be made.
